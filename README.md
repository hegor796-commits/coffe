# Coffee Pre-Order — платформа предзаказа кофе

White-label сервис предзаказа кофе. Одно **Telegram Mini App** с тремя ролями:
**клиент** заказывает, **бариста** видит ленту заказов и ведёт их по статусам,
**админ** (владелец) настраивает меню, точки и сотрудников. Мультитенантный —
одна инсталляция обслуживает много кофеен.

Оплата на MVP — **при получении на кассе** (без интеграции с POS). Онлайн-оплата
(ЮKassa с ключами кофейни) заложена в модель как режим тенанта и включается позже.

Документы: [`TECHNICAL_PLAN.md`](./TECHNICAL_PLAN.md) — техплан, [`PLAN.md`](./PLAN.md) — анализ рисков.

## Архитектура

- **`apps/api`** — backend на NestJS: auth по ролям (валидация Telegram initData → JWT),
  меню с модификаторами, заказы с машиной состояний, стоп-лист, приглашения
  сотрудников, Telegram-бот (grammY), WebSocket (socket.io), очереди BullMQ
  (автоотмена непринятых заказов, уведомления).
- **`apps/tma`** — Mini App на React + Vite: роутинг по роли, экраны клиента,
  бариста и админа, корзина, live-статусы через WebSocket.
- **`packages/shared`** — общий код: enum статусов, машина состояний заказа,
  zod-схемы DTO, расчёт цены. Источник истины для фронта и бэка.

Ключевые технические решения (подробнее — в техплане):
`tenant_id` во всех таблицах + RLS; снапшот позиций заказа в JSONB; деньги в
копейках; цена всегда пересчитывается на сервере; push-уведомления бота — основной
канал доставки заказов бариста (Mini App не живёт в фоне), WebSocket — ускоритель.

## Быстрый старт (локально)

Требуется Node 20+, pnpm 10+, Docker (Postgres, Redis, MinIO).

```bash
pnpm install
cp .env.example apps/api/.env        # впишите TELEGRAM_BOT_TOKEN
pnpm infra:up                        # postgres + redis + minio

cd apps/api
pnpm prisma:generate
pnpm prisma db push                  # применить схему (или db:migrate для миграций)
pnpm db:rls                          # включить RLS-политики (defense-in-depth)
pnpm db:seed                         # демо-кофейня «Demo Coffee» (slug: demo)

# два терминала:
pnpm --filter @coffee/api dev        # API на :3000
pnpm --filter @coffee/tma dev        # Mini App на :5173
```

Для теста Mini App с реального телефона поднимите туннель (например
`cloudflared tunnel --url http://localhost:5173`) и укажите его как Web App URL
в настройках бота у @BotFather. Открыть меню демо-кофейни:
`?startapp=demo`.

Сид создаёт владельца и бариста, привязанных к Telegram id из
`SEED_OWNER_TG_ID` / `SEED_BARISTA_TG_ID` (по умолчанию — плейсхолдеры; впишите
свои id, чтобы зайти под этими ролями).

| Команда | Действие |

| `pnpm typecheck` | Проверка типов |
| `pnpm test` | Юнит-тесты (FSM, расчёт цены, валидация initData) |

## Статус

Реализовано ядро MVP: авторизация по ролям, меню с модификаторами и стоп-листом,
создание заказа с серверным расчётом цены, машина состояний, лента бариста с
кнопками статусов, WebSocket, Telegram-бот и уведомления, автоотмена непринятых
заказов, приглашение сотрудников по ссылке, базовая админка (сотрудники, точки,
стоп-лист). Не реализовано (следующие этапы): онлайн-оплата (ЮKassa), загрузка
фото меню в S3, полноценный редактор меню в админке, биллинг подписки, веб-версия
для клиента, собственный бот тенанта.
